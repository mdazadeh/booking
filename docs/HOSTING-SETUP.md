# راهنمای نصب وقت‌یار روی هاست اشتراکی لینوکس — نسخه آزمایشی ۱.۳

## موارد لازم
- پنل cPanel یا DirectAdmin و امکان File Manager / FTP
- PHP 8.3 یا جدیدتر و افزونه‌های PDO_MySQL، OpenSSL، mbstring، JSON
- MySQL 8 یا MariaDB با InnoDB و تراکنش و FOR UPDATE
- Apache با mod_rewrite، فعال بودن HTTPS/SSL
- یک دیتابیس جدید و کاربر اختصاصی با دسترسی محدود
- امکان تعریف Document Root مستقل و بکاپ روزانه خارج از سرور
- Cron Jobs ترجیحاً فعال؛ نیازی به VPS یا SSH برای اجرای برنامه نیست.

## انتخاب آدرس
اگر دامنه hajarrajaee.ir اختصاصی و بدون سایت موجود است، ریشه آن می‌تواند Document Root سامانه باشد.
اگر روی دامنه سایت فعال وجود دارد، سابدامین booking.hajarrajaee.ir ایجاد کنید و **هرگز public_html سایت موجود را جایگزین نکنید**. در صورت انتخاب سابدامین، آدرس API در android/app/build.gradle.kts را به آدرس جدید تغییر دهید و APK را مجدداً بسازید.

## ساختار آپلود در هاست
booking/
- app/ (خارج از ریشه وب؛ شامل config.php و sync.php)
- sql/ (اسکریپت‌های دیتابیس و migration)
- public/ (Document Root مستقل شامل index.php، .htaccess، r/ و status/)

فایل server/app/config.example.php را به app/config.php کپی و مقادیر واقعی دیتابیس و base_url را فقط در هاست وارد کنید. فایل config.php را هرگز در GitHub یا چت منتشر نکنید.

## مراحل نصب
1. دیتابیس و کاربر اختصاصی بسازید.
2. برای نصب تازه sql/schema.sql را در phpMyAdmin وارد کنید. روی دیتابیس موجود و بدون بکاپ اجرا نکنید.
3. اگر دیتابیس نسخه اولیه قبلاً نصب شده است، پس از بکاپ فقط sql/migrations/002_sync.sql را یک بار اجرا کنید. در نصب تازه این Migration لازم نیست.
4. پوشه public را Document Root دامنه / سابدامین انتخابی کنید؛ app و sql بیرون از دسترسی مرورگر باشند.
5. HTTPS را فعال و HTTP را به HTTPS منتقل کنید؛ Rewrite Rules و API را بررسی کنید.
6. در جدول admins رکورد مدیر با username موردنظر و password_hash تولیدشده توسط تابع PHP password_hash ایجاد کنید. رمز خام را در مخزن نگذارید.
7. تست: ورود معتبر، ساخت لینک اختصاصی، ثبت درخواست، تأیید مدیر، پیگیری وضعیت، تعارض رزرو هم‌زمان.
8. در گوشی به تنظیمات → همگام‌سازی سرور بروید و مشخصات مدیر **سرور** را وارد کنید. ورود محلی اندروید و ورود سرور تا تنظیم کاربر سرور مستقل‌اند.
9. آزمون همگام‌سازی دوطرفه زمان‌ها، تغییر و لغو نوبت و گزارش تعارض.
10. بکاپ روزانه دیتابیس و آزمون واقعی بازیابی را فعال کنید.

## وضعیت امنیت و محدودیت‌ها
- صفحه مشتری فقط با لینک خصوصی باز می‌شود؛ نصب برنامه توسط مشتری لازم نیست.
- داده‌های نوبت و نام/تلفن به سرور منتقل می‌شوند؛ شرح حال و یادداشت‌ها در نسخه بتا فقط روی گوشی ذخیره‌اند.
- بعضی داده‌های ساختاری نوبت در SQLite محلی رمزنگاری سرتاسری نشده‌اند. هنوز نباید اطلاعات حساس واقعی وارد شوند.
- بکاپ قابل حمل با رمز مستقل AES-256-GCM است؛ بازیابی داده فعلی را جایگزین می‌کند.
- WorkManager همگام‌سازی دوره‌ای (حداقل ۱۵ دقیقه، وابسته به محدودیت باتری) را اجرا می‌کند؛ همگام‌سازی فوری تضمین نمی‌شود.
- قبل از انتشار باید امنیت، تست هم‌زمانی و تست POCO F4 انجام شود.

## اطلاعاتی که برای راه‌اندازی نیاز است
1. نوع کنترل پنل هاست و نسخه PHP/MySQL
2. آیا دامنه اصلی سایت فعال دارد یا آزاد است؟
3. وجود SSL و تنظیم DNS دامنه / سابدامین
4. امکان Document Root مستقل و مدیریت دیتابیس
5. دیتابیس جدید یا نیازمند Migration بودن
6. محل بکاپ خارج از هاست و میزان ترافیک تقریبی

**هیچ رمز عبور هاست یا دیتابیس را در چت ارسال نکنید.**
